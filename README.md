# 🛍️ Wildberries Parser Bot — сбор отзывов и вопросов

Telegram-бот для парсинга отзывов и вопросов с Wildberries.  
Отправьте артикул или ссылку на товар — бот загрузит страницы с отзывами и вопросами через реальный браузер (DrissionPage, **не Selenium**), соберёт данные и пришлёт Excel-файлы и ZIP-архив.

## 📋 Возможности

- Принимает **ссылку на товар** Wildberries или **чистый артикул**
- **Гибкая фильтрация отзывов по звёздам** (до сбора, не после):
  - ⭐ Все отзывы
  - ⭐ 1★ / 1–2★ / 1–3★ / 4–5★
  - 🔢 **Ручной выбор галочками** (можно отметить, например, только 2★ и 5★)
- **Вопросы собираются всегда полностью** (без фильтра)
- **Прогресс в реальном времени** («Собрано X из ~Y»)
- **Сводка после сбора**: количество отзывов (до/после фильтра), вопросов, средний рейтинг
- **Три файла на выходе**:
  - `Отзывы_артикул_фильтр.xlsx`
  - `Вопросы_артикул.xlsx`
  - `Архив_артикул_фильтр.zip`
- **История последних 5 запусков** (`/history`) с кнопками для повторного скачивания без пересбора
- **Белый список Telegram ID** — доступ только вам
- **Человеческие сообщения об ошибках** на русском языке
- **Асинхронная работа** — бот не зависает во время долгого сбора

## 🚀 Быстрый старт (развёртывание на VPS)

### 1. Получите токен бота и ваш Telegram ID

- Напишите [@BotFather](https://t.me/BotFather), создайте бота и получите **токен** (вида `123456:ABC...`).
- Узнайте ваш Telegram ID через [@userinfobot](https://t.me/userinfobot) или другой сервис.

### 2. Скопируйте проект на сервер

```bash
git clone https://github.com/lavren007/wb-parser-bot.git
cd wb-parser-bot
```

### 3. Настройте переменные окружения

```bash
cp .env.example .env
nano .env
```

Содержимое `.env`:

```
BOT_TOKEN=ваш_токен_от_BotFather
WHITELIST=ваш_telegram_id
```

Если у вас несколько пользователей, укажите их через запятую: `WHITELIST=111111,222222`.

### 4. Запустите бота через Docker Compose

```bash
docker compose up -d --build
```

После этого бот будет работать в фоне. Проверьте логи:

```bash
docker compose logs -f
```

Если всё хорошо, вы увидите:

```
✅ Бот запущен. Ожидаю сообщения...
```

## 💬 Как общаться с ботом

### 1. Запуск

Отправьте команду `/start` (или просто нажмите кнопку «Старт» в Telegram).  
Бот ответит:

```
👋 Привет! Я парсер отзывов и вопросов Wildberries.

Отправь мне ссылку на товар или артикул, и я соберу данные.
Пример ссылки: https://www.wildberries.ru/catalog/12345678/detail.aspx
Или просто: 12345678

📋 Команда /history — история последних 5 запусков.
```

### 2. Отправка товара

Отправьте ссылку или артикул, например:  
`https://www.wildberries.ru/....`  
или просто `12345678`.

Бот подтвердит:

```
✅ Товар найден! Артикул: 12345678

Выберите фильтр для отзывов:
[⭐ Все отзывы] [⭐ 1★]
[⭐ 1–2★] [⭐ 1–3★]
[⭐ 4–5★] [🔢 Выбрать вручную (галочками)]
```

### 3. Выбор фильтра

- Нажмите на одну из кнопок, чтобы задать диапазон оценок.
- Если выбрали **«Выбрать вручную (галочками)»**, появится клавиатура с отдельными звёздами. Отметьте нужные (например, только 2★ и 5★) и нажмите **«✅ Готово»**.

### 4. Сбор данных

После выбора фильтра бот начнёт собирать данные:

```
⏳ Запускаю сбор данных...
Артикул: 12345678
Фильтр: 1-3★

🔍 Собираю данные...
Отзывы: 12 из ~33
Вопросы: загрузка...
```

### 5. Получение результата

Когда сбор завершится, бот пришлёт сводку:

```
✅ Сбор завершён!

📦 Артикул: 12345678
🔍 Фильтр: 1-3★
⭐ Отзывов собрано: 33 (всего 148 без фильтра)
❓ Вопросов собрано: 32
📊 Средний рейтинг: 2.1

Отправляю файлы...
```

И сразу после этого — три файла:
- `Отзывы_12345678_1-3★.xlsx`
- `Вопросы_12345678.xlsx`
- `Архив_12345678_1-3★.zip`

### 6. История запусков

В любой момент можно вызвать `/history`. Бот покажет последние 10 запросов с кнопками для повторного скачивания файлов.

## 🛠 Технические детали
## ⚙️ Как это работает (подробное описание)

### 1. Получение артикула
Пользователь отправляет боту **ссылку** на товар Wildberries или **чистый артикул** (цифровой идентификатор товара).  
Бот распознаёт артикул с помощью регулярных выражений (поддерживаются ссылки вида `/catalog/12345678/detail.aspx`, `product?card=...` и т.д.).

### 2. Загрузка страниц отзывов и вопросов
Бот **не использует** официальный API Wildberries (т.к. он требует токена продавца) и **не пытается** получить `imt_id` товара через карточку.  
Вместо этого он напрямую открывает публичные страницы в реальном браузере Chromium (DrissionPage):

- **Отзывы**: `https://www.wildberries.ru/catalog/{article}/feedbacks?size=100`
- **Вопросы**: `https://www.wildberries.ru/catalog/{article}/questions`

Браузер работает в **headful-режиме** (с виртуальным дисплеем Xvfb), что позволяет обходить большинство антибот-защит Wildberries без прокси.

### 3. Извлечение данных
После загрузки страницы браузер выполняет несколько прокруток (`window.scrollTo`), чтобы активировать ленивую подгрузку всех отзывов/вопросов.  
Затем HTML-код страницы парсится с помощью **BeautifulSoup**. Данные извлекаются по точным CSS-селекторам:

#### Для отзывов:
- **Автор**: `.feedback__header`
- **Оценка**: `span.stars-line` (класс `star1`–`star5`)
- **Текст**: `p.feedback__text.j-feedback__text`
- **Достоинства**: `.feedback__text--item-pro` (с удалением заголовка)
- **Недостатки**: `.feedback__text--item-con` (аналогично)
- **Дата**: `.feedback__date`
- **Ответ продавца**: `.feedback__text--sellers-reply`

#### Для вопросов:
- **Автор**: `.feedback__header`
- **Текст вопроса**: `.feedback__text`
- **Дата**: `.feedback__date`
- **Ответ продавца**: `.feedback__text--sellers-reply__question` (или общий `.feedback__text--sellers-reply`)

Если JavaScript-селекторы не дают результатов (например, из-за изменений вёрстки), бот автоматически переключается на парсинг HTML через BeautifulSoup.

### 4. Фильтрация отзывов по звёздам
После извлечения всех отзывов применяется фильтр, выбранный пользователем:
- `all` — без фильтрации
- `1`, `2`, `3`, `4`, `5` — только отзывы с указанной оценкой
- `1-2`, `1-3`, `4-5` — диапазоны
- `2,5` — кастомный набор (выбранный галочками)

Фильтрация происходит до генерации Excel-файла, что экономит ресурсы и время.

### 5. Генерация Excel-файлов
На основе отфильтрованных отзывов и всех вопросов создаются три файла:

- **`Отзывы_[артикул]_[фильтр].xlsx`** — содержит колонки: дата, автор, оценка, текст, достоинства, недостатки, ответ продавца, дата ответа, фото/видео.
- **`Вопросы_[артикул].xlsx`** — колонки: дата, автор, текст вопроса, ответ продавца, дата ответа, ответы других покупателей.
- **`Архив_[артикул]_[фильтр].zip`** — архив с обоими Excel-файлами.

Файлы сохраняются в папке `temp/` внутри контейнера.

### 6. Отправка пользователю
Бот редактирует сообщение с прогрессом и выводит сводку (количество отзывов, вопросов, средний рейтинг), а затем отправляет три документа через Telegram API.  
Данные также записываются в SQLite-базу (`history.db`) для возможности повторного скачивания через `/history`.

### 7. Повторное скачивание
Команда `/history` показывает последние 10 запросов. При нажатии на кнопку «Скачать #N» бот отправляет ранее сгенерированные файлы из папки `temp/` без повторного сбора данных.

### 8. Безопасность
Доступ к боту ограничен белым списком Telegram ID, заданным в `.env`. Неавторизованные пользователи получают сообщение об ошибке.

### Как работает сбор данных?

Бот использует библиотеку **DrissionPage** (управляет реальным браузером Chromium через DevTools Protocol).  
Браузер запускается в контейнере с виртуальным дисплеем `Xvfb`.

Процесс для каждого артикула:
1. Открывается страница отзывов `.../feedbacks?size=100`.
2. Выполняется несколько прокруток для подгрузки всех отзывов.
3. HTML парсится (BeautifulSoup) или данные извлекаются через JavaScript.
4. Аналогично открывается и парсится страница вопросов `.../questions`.
5. Собранные данные фильтруются по выбранным оценкам (если нужно).
6. Генерируются Excel-файлы и ZIP-архив.

### Почему не используется официальный API?

Официальный API Wildberries требует токена продавца, который есть не у всех. Публичные API (`feedbacks1.wb.ru`, `card.wb.ru`) часто блокируют запросы по IP или требуют сложных сессионных кук.  
Прямой парсинг страниц через браузер позволяет обойти эти ограничения без использования прокси.

## ⚠️ Возможные проблемы и их решение

### 1. Бот не отвечает на команды

- Проверьте, что в `.env` правильно указан `BOT_TOKEN` и ваш `WHITELIST` (числа через запятую, без пробелов).
- Посмотрите логи: `docker compose logs -f`. Если есть ошибки импорта, пересоберите образ: `docker compose build --no-cache`.

### 2. Файлы Excel пустые или содержат неверные данные

- Убедитесь, что товар доступен на Wildberries и имеет отзывы/вопросы.
- Проверьте логи: `docker compose logs | grep FEEDBACKS`. Там будет указано, сколько отзывов найдено.
- Если отзывов 0, а на сайте они есть, возможно, изменилась вёрстка Wildberries. Напишите разработчику.

### 3. Бот долго собирает данные

- При большом количестве отзывов (>100) сбор может занимать 1–2 минуты из-за прокруток страницы. Это нормально.
- Если сбор зависает, перезапустите контейнер: `docker compose restart`.

### 4. Ошибка `Server is already active for display 99`

Остановите контейнер и удалите старый lock-файл:

```bash
docker compose down
rm -f /tmp/.X99-lock
docker compose up -d
```
